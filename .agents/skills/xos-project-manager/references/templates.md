# Reusable Templates

## Project brief

```markdown
# Project Brief: [Name]

## Problem and target users
## Desired outcome and success measures
## Goals
## Non-goals
## Core user journeys
## MVP scope
## Constraints, assumptions, and dependencies
## Risks and open questions
## Recommended next decision
```

## Task specification

```markdown
## [TASK-ID] [Title]
- **Outcome:**
- **Why:**
- **Owner:**
- **Priority:** Must / Should / Could
- **Dependencies:**
- **Acceptance criteria:**
  - [ ]
- **Verification:**
- **Risks / notes:**
```

## Status report

```markdown
# Project Status — [Date]
- **Overall:** On track / At risk / Blocked — [evidence]
- **Done:** Verified outcomes
- **In progress:** Work, owner, expected outcome
- **Blocked:** Blocker, impact, required action
- **Risks:** Risk, impact, mitigation
- **Decisions needed:** Question and recommendation
- **Next:** Ordered priorities
```

## Release checklist

```markdown
# Release Readiness — [Name / Version]
- [ ] Scope and acceptance criteria verified
- [ ] Required tests and reviews recorded
- [ ] Critical defects resolved or explicitly accepted
- [ ] Configuration and migration steps ready
- [ ] Deployment owner and steps identified
- [ ] Smoke checks and monitoring ready
- [ ] Rollback trigger and steps documented
- [ ] Release notes and known limitations prepared
- [ ] Post-release owner and review window set
```
